# Image Canvas

这是一块用来生成图片的画布。在无限延伸的画布上写下想法，每一张画好的图像都可以自由拖动、整理收藏，或者直接当作参考图继续往下延伸。

## 快速开始

想要让我动笔，总得先搭好我们的专属画室。请确保你的电脑中已经安装了 Node.js（推荐 20 及以上版本）与 [pnpm](https://pnpm.io)。

### 启动开发环境

```bash
pnpm install
pnpm dev
```

在浏览器中打开 <http://localhost:5173>。开发模式下前端运行在 5173 端口，所有 `/api` 请求会自动转发给 8787 端口的后端服务。

### 生产环境运行

如果你希望像日常应用一样轻快运行：

```bash
pnpm build
pnpm start
```

构建完成后，后端服务会直接托管前端页面，访问 <http://127.0.0.1:8787> 即可。

### 常用命令

| 命令 | 说明 |
| --- | --- |
| `pnpm dev` | 同时启动后端服务与前端开发服务器 |
| `pnpm build` | 执行类型检查并构建前端资源 |
| `pnpm start` | 启动后端服务（若存在 `dist/` 目录则一并托管前端） |
| `pnpm typecheck` | 仅执行 TypeScript 类型检查 |

### 环境变量

如果你需要调整画室的运行参数，可以通过以下环境变量进行配置：

| 变量名 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `8787` | 后端服务监听端口 |
| `DATA_DIR` | `data` | 数据存储目录，用于保存配置、项目与图片文件 |
| `LOG_LEVEL` | `info` | 后端日志输出级别 |

> **安全提示**：后端服务默认只监听本地的 `127.0.0.1`，不对局域网开放。毕竟你的 API Key 会保存在本地数据目录中，这可是我们的秘密，可不能随随便便透露给外人。

## 配置接口

想要让我真正挥洒色彩，还需要接入你准备的模型服务。点击界面右上角的「设置」图标：

1. **填写接口地址与密钥**：输入接口基地址与 API Key。接口协议需要兼容 OpenAI 的图像规范：没有参考图时调用 `{基地址}/images/generations`，带有参考图时调用 `{基地址}/images/edits`。
2. **检测可用模型**：点击「检测可用模型」按钮，系统会请求 `{基地址}/models` 获取模型列表。你可以输入关键词进行筛选，然后逐个添加或者一键全部添加；当然，也支持手动输入模型名称。
3. **设置默认模型与单价**：在「模型列表」中指定一个默认使用的模型，并填写单张图片的预估单价。画布上方统计的消耗金额会按照这个价格进行累加（仅供参考）。

> **贴心提示**：如果基地址和密钥全部留空，我会自动切换为演示模式，直接为你展示预置样图，不会产生任何网络请求或费用。

## 使用画布

这块画布没有边界，只要灵感还在，我们的创作就不会停下。以下是一些让你操作起来更顺手的小技巧：

- **双击新建**：在画布空白区域双击鼠标，写下你的提示词，挑选合适的模型、画幅比例与分辨率，按下回车即可开始绘制（换行请按下 `Shift + 回车`）。
- **平移与缩放**：按住鼠标拖动画布空白处可以自由平移，滑动鼠标滚轮即可平滑缩放视角。
- **导入参考图**：把本地图片文件直接拖拽到画布或资料库中，就能当作后续作画的垫图参考。
- **连续调整**：点击选中任意一张图片，在屏幕下方的操作栏输入新的修改想法（比如「换成雨夜街景」）并继续生成；也可以点「重新生成」另出一版，提示词留空时沿用原来的提示词，模型、画幅和尺寸按操作栏当前的选择，旧的一版会自动收进资料库。此外还可以加入收藏、复用提示词或下载到本地。
- **多图组合**：按住 `Shift` 键连续点击多张图片，操作栏会自动按照编号将它们打包作为参考图。使用 `◀` 与 `▶` 按钮可以随时调整它们的先后次序。
- **连接创作节点**：拖动图片右侧的连接小圆点，接入新的创作节点，连接顺序就是发送给模型的参考图次序；双击连接线即可将其删除。
- **整理资料库**：点击右上角的「资料库」面板，集中浏览与管理所有已经生成的历史画作。从画布删除的图片会以灰色标记保存在这里，只有在这里才能彻底删除图片。
- **切换独立项目**：点击左上角的项目菜单，可以随时新建或切换不同的项目。每个项目都拥有完全独立的画布空间。
- **快捷取消**：按下键盘上的 `Esc` 键，可以随时取消当前选中状态并关闭所有浮层面板。

## 数据存储目录

所有配置和创作内容都会妥善保存在你本地的数据目录中，默认位于项目根目录的 `data/` 文件夹：

```text
data/
  settings.json                      接口基地址、API Key、模型列表与默认偏好
  logs/                              运行日志文件
  projects/<id>/project.json         项目名称与画布视角位置
  projects/<id>/nodes.json           画布节点与连线元数据
  projects/<id>/images/<nodeId>.<ext> 生成的图片与参考图原文件
```

> **重要提醒**：`settings.json` 文件中包含明文保存的接口密钥。为了保障你的资产安全，请切勿将 `data/` 目录提交至公开代码仓库或发送给他人。

## 皮肤

应用的名称、头像、生成中的动图和「关于」页的附加说明可以通过皮肤替换。皮肤是放在项目根目录 `skin/` 里的一个独立仓库，只含 `skin.json` 和图片，不含代码。`skin/` 已被 `.gitignore` 忽略，不会进入本仓库的提交。

```bash
pnpm skin:install <皮肤仓库的 git 地址>   # 克隆到 skin/
pnpm skin:update                          # 拉取最新皮肤
pnpm skin:remove                          # 移除皮肤，回到默认外观
```

### 推荐皮肤

| 皮肤 | 说明 | 安装 |
| --- | --- | --- |
| [remie-canvas-skin](https://github.com/momakoding/remie-canvas-skin) | 「蕾米」主题，换掉名称、头像、生成中的动图，并在「关于」页附带版权声明 | `pnpm skin:install https://github.com/momakoding/remie-canvas-skin.git` |
| big-fat-fish | 即将推出 | 暂无 |

### 自己做一套皮肤

`skin.json` 的字段：

| 字段 | 说明 |
| --- | --- |
| `brand` | 顶栏和「关于」页显示的名称 |
| `subtitle` | 名称后的副标题，可省略 |
| `tagline` | 「关于」页的简介 |
| `mascot` | 头像文件名，放在 `skin/` 下 |
| `drawing` | 生成中的动图文件名，放在 `skin/` 下 |
| `aboutSections` | 「关于」页附加段落，格式为 `[{ "title": "...", "paragraphs": ["..."] }]` |
